Подключите свой ИИ

Студия работает сразу — локальные шаблоны доступны без ключа. Чтобы получать индивидуальный код от языковой модели, настройте сервер.

Проверяем подключение…
1. Задайте ключ на сервереКлюч хранится только в окружении сервера — не вставляйте его в браузер.
OPENAI_API_KEY=ваш_ключ npm start
2. Перезапустите приложениеМожно выбрать совместимую модель через переменную OPENAI_MODEL.
OPENAI_MODEL=gpt-4o-mini
