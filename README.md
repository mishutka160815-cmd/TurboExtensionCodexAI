# TurboBlocks — генератор расширений Scratch

Небольшая веб-студия для создания пользовательских расширений Scratch 3.0. Она работает без ключей: локальный генератор собирает готовый JavaScript-каркас и библиотеку полезных блоков. Если настроить OpenAI-совместимый API на сервере, вместо локального шаблона будет использоваться языковая модель.

## Запуск

Нужен Node.js 20 или новее. Зависимости устанавливать не нужно.

```bash
npm start
```

Откройте адрес, напечатанный сервером (по умолчанию `http://localhost:4173`). Для разработки с автоматическим перезапуском:

```bash
npm run dev
```

## Подключение ИИ

Ключ задаётся только в окружении Node-сервера; фронтенд и браузер его не получают. В macOS/Linux:

```bash
OPENAI_API_KEY="ваш_ключ" npm start
```

В PowerShell:

```powershell
$env:OPENAI_API_KEY="ваш_ключ"
$env:OPENAI_MODEL="gpt-4o-mini"
npm start
```

По умолчанию используется модель `gpt-4o-mini`. Её можно заменить переменной `OPENAI_MODEL`. Для совместимого API-провайдера можно задать `OPENAI_BASE_URL`, например `https://your-provider.example/v1`.

Без `OPENAI_API_KEY` студия автоматически работает в локальном режиме. Если подключённый API временно недоступен, приложение всё равно создаст локальный вариант расширения.

## Использование

1. Опишите нужные блоки, выберите категорию или оставьте автоопределение.
2. Нажмите **Сгенерировать расширение**. Вкладка **Блоки** показывает палитру, **Код** — исходный JavaScript, а **Как запустить** — дальнейшие шаги.
3. Скопируйте код или скачайте `.js`. Последние результаты сохраняются в библиотеке этого браузера.
4. Для тестирования пользовательского расширения используйте редактор TurboWarp и его функцию загрузки пользовательских расширений. Произвольные расширения не загружаются напрямую на сайт Scratch.

Приложение не исполняет сгенерированный код. Перед загрузкой проверьте его содержимое и необходимые разрешения, особенно если расширение обращается к сети или устройствам.
